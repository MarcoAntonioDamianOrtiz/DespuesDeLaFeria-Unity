# 7. NUEVO SISTEMA VISUAL DE MANCHAS

Quiero que las manchas se vean mucho mejor.

Actualmente necesito más variedad y credibilidad visual.

### Tipos de manchas

Crea variantes relacionadas con residuos que pueden encontrarse después de una feria.

Por ejemplo:

**Refresco de cola**
- Marrón oscuro.
- Bordes irregulares.
- Aspecto ligeramente brillante.

**Refresco de naranja**
- Naranja translúcido.
- Forma de líquido derramado.

**Gaseosa de fresa**
- Rosado o rojo suave.

**Jugo**
- Amarillo o anaranjado.
- Diferentes formas.

**Bebida de uva**
- Morado.

**Grasa de alimentos**
- Tonos marrones y amarillentos.
- Superficie irregular.

**Suciedad común**
- Gris o marrón.
- Acumulación de polvo.

### Requisitos visuales

Quiero que cada mancha pueda variar en:

- Tamaño.
- Forma.
- Color.
- Opacidad.
- Brillo.
- Posición.
- Rotación.

No quiero círculos idénticos con diferentes colores.

Puedes crear texturas originales, máscaras, decals compatibles con URP o shaders apropiados.

### Limpieza progresiva

Cuando el jugador limpia una mancha:

1. Debe detectarse correctamente la interacción.
2. Debe comenzar la animación del trapo.
3. La mancha debe reducirse visualmente.
4. El progreso individual debe actualizarse.
5. Deben reproducirse sonidos apropiados.
6. Al llegar al 100%, la mancha desaparece.
7. El contador global se actualiza.
8. El resultado se guarda correctamente.

La apariencia visual debe reflejar el progreso real de limpieza.

# 8. MEJORAR LA ESCOBA

Quiero una escoba mucho mejor diseñada.

Si el modelo actual no es adecuado, crea uno nuevo.

Debe tener:

- Mango con proporciones correctas.
- Cabezal bien definido.
- Cerdas visibles.
- Materiales adecuados.
- Posición correcta en primera persona.

### Animaciones

Mejora:

- Reposo.
- Movimiento al caminar.
- Inicio de barrido.
- Barrido continuo.
- Detención.
- Contacto visual con el suelo.

La escoba debe transmitir cierta sensación de peso.

### Efectos

Cuando se barre:

- Las hojas reaccionan.
- Aparece polvo ligero.
- Se escucha fricción.
- Los residuos se desplazan cuando corresponde.
- La limpieza responde a la posición real de la herramienta.

Evita que la escoba limpie objetos que están claramente fuera de su alcance.

### Diseño

Debe incluir:

- Forma de tela ligeramente irregular.
- Pliegues.
- Bordes naturales.
- Espesor apropiado.
- Material con apariencia textil.
- Color y textura acordes con el juego.

### Movimiento

- El trapo debe moverse sobre la superficie.
- Debe tener animación de frotado.
- Debe reaccionar visualmente al contacto.
- Debe sincronizarse con el sonido.
- Debe acompañar la desaparición progresiva de la mancha.
