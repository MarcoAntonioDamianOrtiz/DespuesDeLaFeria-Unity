# Primera zona: El rincón de las canicas

## Fantasía y límites

Recuperar el color y la actividad de una feria al amanecer mediante tareas manuales agradables. Primera persona, un jugador, sin cronómetro, economía ni mejoras en esta prueba.

## Secuencia

1. Organizar el carrito y barrer los residuos hacia el recogedor.
2. Limpiar las manchas del mostrador con el paño.
3. Colocar el cartel caído.
4. Encender el puesto y probar la canica.

Las tres primeras tareas se pueden alternar. El final exige completarlas. La ayuda con Tab señala un objetivo pendiente; no completa el trabajo.

## Dirección artística de esta fase

Feria artesanal de madera pintada: verde petróleo, coral, marfil y amarillo cálido. Toldo con volumen, banderines triangulares, marcos de latón pintado y carteles ilustrados de canicas y amanecer.

Las herramientas comparten materiales y colores con el puesto. Los iconos reflejan sus formas. Se conservan fuentes SVG y generadores de geometría para cambiar el diseño sin depender de paquetes externos.

## Criterio para la siguiente fase

Probar con jugadores una sesión completa y observar si el barrido sigue siendo agradable, si orientan el recogedor con facilidad, si distinguen las herramientas y si encuentran las tareas pendientes. La siguiente ampliación debe responder a esa observación; no se añaden más puestos únicamente para alargar la partida.
